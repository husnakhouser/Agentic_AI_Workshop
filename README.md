# Research Paper Answer Bot (RAG + Streamlit)

A research-paper question-answering app based on the supplied notebook. It uses:
- **Groq API** for answer generation
- **ChromaDB** for persistent vector search
- **Sentence Transformers** for local embeddings
- Dense, MMR, BM25, hybrid RRF, reranking, and multi-query retrieval strategies
- Source snippets with paper title and page references

## Project files

```text
research_paper_rag_streamlit/
├── app.py
├── rag_core.py
├── local_models.py
├── requirements.txt
├── README.md
├── .gitignore
└── .streamlit/
    └── secrets.toml.example
```

## Important: build the index before running the app

The notebook saves deployment artifacts to `artifacts/`, especially:
- `artifacts/index_meta.pkl`
- `artifacts/chroma/`

Those files are **not generated by simply extracting the Python files**. Run the uploaded notebook through the data-loading, chunking, embedding/vector-store, and retrieval-selection sections (at least through Section 5, and ensure the final selected settings are saved). Copy the resulting `artifacts/` folder into this project. The app will not start without `artifacts/index_meta.pkl` and the matching ChromaDB collection.

If your notebook creates a very large index, do not push it to ordinary GitHub. Use a permitted storage option or rebuild the index during deployment. Streamlit Community Cloud has resource and storage limits, so a large local embedding model may exceed available RAM/time.

## Run locally (Windows PowerShell)

1. Create and activate a virtual environment:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

2. Add your Groq API key. Option A: create `.streamlit/secrets.toml` (copy from `.streamlit/secrets.toml.example`) and replace the placeholder:

```toml
GROQ_API_KEY = "gsk_your_real_key"
```

Do not commit `secrets.toml` or paste your key into source code.

3. Ensure the `artifacts/` folder is present, then run:

```powershell
streamlit run app.py
```

## Push to GitHub

Run these commands from the project directory after checking the files and index size:

```bash
git init
git add app.py rag_core.py local_models.py requirements.txt README.md .gitignore .streamlit/secrets.toml.example
git commit -m "Add research paper RAG Streamlit app"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
git push -u origin main
```

If `artifacts/` is small enough and you intend to version it, add it explicitly with `git add artifacts/`. GitHub blocks files over 100 MB; large vector stores should not be pushed directly. Never commit API keys.

## Deploy on Streamlit Community Cloud

1. Push the project to GitHub.
2. In Streamlit Community Cloud, choose **Create app**, select the repository, branch `main`, and main file `app.py`.
3. In the app's **Settings → Secrets**, add:

```toml
GROQ_API_KEY = "gsk_your_real_key"
```

4. Deploy. Make sure the required `artifacts/index_meta.pkl` and `artifacts/chroma/` data are available to the running app. If they are absent, the app reports that the index is missing.

## Troubleshooting

- **`index_meta.pkl not found`**: copy/build the notebook's `artifacts/` directory into the project.
- **Groq API/model error**: check the API key and the model IDs available to your Groq account; set `LLM_MODEL` if necessary.
- **Chroma SQLite error**: `pysqlite3-binary` is included for Linux deployment.
- **Memory/resource errors**: the embedding model and reranker download weights on first use. Try a smaller embedding model or a host with more RAM.
